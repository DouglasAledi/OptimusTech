Landing page moderna desenvolvida para apresentação de uma empresa de tecnologia. O projeto inclui seções institucionais, exibição de métricas operacionais, quadro de vagas abertas com faixas salariais, depoimentos de colaboradores e formulário para captura de e-mails.

---

## 📌 Destaques da Implementação

- 🏗️ **HTML5 Semântico:** Estruturação limpa utilizando tags adequadas (`<header>`, `<main>`, `<footer`) garantindo melhor acessibilidade e boas práticas de SEO.
- 🎨 **CSS Modular:** Organização da estilização dividida em arquivos independentes (`header.css`, `main.css`, `footer.css`) para facilitar a manutenção e escalabilidade do código.
- 🏷️ **Nomenclatura BEM (Block Element Modifier):** Padrão de escrita de classes CSS para evitar conflitos de escopo e manter a clareza da arquitetura frontend.
- 💼 **Seção de Carreiras & Depoimentos:** Layout focado na experiência do usuário para exibição de oportunidades e prova social.
